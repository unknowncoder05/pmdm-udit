# UDITflix

Catálogo Flutter de vídeos, cómics y juegos con portadas locales, filtros por formato y fichas de contenido. El visor muestra la portada de cada título.

## Ejecutar en el navegador

Desde esta carpeta, con Flutter y Dart 3.8.1 o superior instalados, ejecuta:

```sh
flutter pub get
flutter run -d chrome
```

Para comprobar el proyecto, ejecuta `flutter test`. Para generar la versión web en `build/web/`, ejecuta `flutter build web`.
