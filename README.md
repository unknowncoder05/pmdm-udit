# PMDM · UDIT · Tarjeta de presentación

## Reto 3 · Escudo 400

Aplicación Android que bloquea llamadas del prefijo comercial español 400 y permite
gestionar una lista blanca de excepciones. Incluye activación del filtrado,
historial de decisiones y almacenamiento local.
